# Lia — Fase 1: Voz + Cérebro + Central — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** At the end of this phase, the user can:

- open Lia from a desktop shortcut,
- press `Ctrl+Alt+Espaço`, speak in Portuguese, and hear Lia answer by voice,
- see the holographic central (model C) with the animated core, the caption and the system panel,
- approve or cancel every PC-changing action on a PODE / CANCELAR card, by click or by voice.

**Architecture:** One Python process (`lia.app`) owns the window (pywebview), the tray icon, the hotkey, the microphone and the speaker.

For every user utterance it spawns the installed `claude` CLI in print mode. Settings:

- output is streamed JSON;
- a Lia-specific working directory;
- a Lia MCP server (`lia.mcp_server`, launched by `claude` over stdio) set as the permission prompt tool.

When `claude` wants to do something not pre-allowed, the MCP server POSTs the request to a tiny HTTP bridge inside the app (127.0.0.1, random token). The bridge shows the card and blocks until the user answers or 60 s pass.

**Tech Stack:** Python 3.12, pywebview (WebView2), pystray + Pillow, keyboard, sounddevice + numpy, faster-whisper (with its Silero VAD), edge-tts + miniaudio, piper-tts (fallback), psutil, mcp (FastMCP), pytest.

**Spec:** `docs/2026-10-29-lia-design.md`. Approved UI reference: `.superpowers/brainstorm/1953-1793317207/content/interface-estilos.html`, option C.

**Out of this phase (separate plans later):** Gmail/Agenda (fase 2), WhatsApp (fase 3), wake word "Lia" + barge-in (fase 4). In this phase the Agenda, Gmail and WhatsApp panels render with the text `EM BREVE`.

## Global Constraints

- **Zero extra cost.** The `claude` subprocess env must never contain `ANTHROPIC_API_KEY` (nor `ANTHROPIC_AUTH_TOKEN`). If either is present in Lia's own env, it is stripped and the caption shows `Aviso: chave de API removida para não gerar cobrança.`
- **Plan quota.** Panels never call `claude`. Only a user utterance does.
- **Language.** All UI text and speech are in pt-BR. The voice is `pt-BR-FranciscaNeural` (edge-tts). The fallback is Piper `pt_BR-faber-medium`.
- **Confirmation (user decision 2a).**
  - Everything that changes the PC needs the card. The pre-allowed tools are only `Read`, `Glob`, `Grep`, `mcp__lia__lia_abrir`, and the Bash read-only allowlist in Task 4.
  - Card timeout: 60 s → deny.
- **Voice approval.**
  - Accepted only after Lia finishes reading the card aloud, and within 15 s.
  - Approval phrases: `pode`, `pode mandar`, `pode fazer`, `confirma`, `confirmo`, `sim pode`. Anything else, including ambiguous phrases, = cancel.
  - The mic is ignored while Lia speaks.
- **Reach (user decision 3c).**
  - `claude` gets `--add-dir` for every fixed drive.
  - Lia never runs elevated. Admin actions go through `mcp__lia__lia_admin`, which goes through the card and then the Windows UAC prompt.
- **Session.** New `claude` session on every app start, and after 2 h without conversation.
- **Startup.** Lia does not start with Windows. Closing the window only hides it; `Sair` in the tray quits.
- **Audio privacy.** Never write audio to disk.
- **Activation.** Hotkey default `Ctrl+Alt+Space`, configurable.
- **Whisper model.** `medium` if CUDA is available, otherwise `small`. Language `pt`. End of speech = 0.8 s of silence.

## Review Focus

1. **No microphone, or mic unplugged mid-session** → Lia shows and speaks `Não encontrei um microfone.` instead of crashing. Test in Task 7.
2. **Hotkey pressed while Lia is still thinking or speaking** → the current speech stops, and the new utterance is queued after the in-flight `claude` call. A second `claude` process never runs in parallel. Test in Task 10.
3. **`claude` missing, not logged in, or quota limit hit** → spoken, human message, and panels keep working. Tests in Task 3.
4. **Offline** → edge-tts fails, so Piper speaks. If `claude` fails, Lia says `Estou sem conexão agora.` Tests in Tasks 3 and 8.
5. **Window hidden, or app quitting while a card is pending** → the request is denied, never left hanging and never auto-approved. Test in Task 5.

### Task 3: Brain — claude subprocess wrapper

**Files:**
- Create: `lia/brain.py`
- Test: `tests/test_brain.py`, `tests/fixtures/stream_ok.jsonl`, `tests/fixtures/stream_limit.jsonl`

**Interfaces:**
- Consumes: `Config`, `ensure_workspace`.
- Produces:
  - `clean_env(env: dict[str, str]) -> tuple[dict[str, str], bool]`. Removes `ANTHROPIC_API_KEY` and `ANTHROPIC_AUTH_TOKEN`. The bool is True if anything was removed.
  - `fixed_drives() -> list[str]`, e.g. `["C:\\", "D:\\"]`. Built from `psutil.disk_partitions()`, keeping `fixed` drives only.

    - `--output-format stream-json --verbose --include-partial-messages`
    - `--session-id <id>` on the first turn, or `--resume <id>` on later turns
    - `--mcp-config <path> --strict-mcp-config`
    - `--permission-prompt-tool mcp__lia__lia_confirmar`
    - `--allowedTools <...>`

    The prompt text is written to stdin, not argv, so quotes and accents are safe.
  - `@dataclass BrainEvent(kind: Literal["text", "done", "error"], text: str = "")`
  - `parse_line(line: str) -> BrainEvent | None`:
    - `stream_event` / `content_block_delta` / `text_delta` → `text`
    - `result` with `is_error: false` → `done`
    - `result` with `is_error: true`, or invalid JSON → `error` carrying the message
    - anything else → `None`
  - `friendly_error(msg: str) -> str` returns:
    - for a limit (regex `(?i)limit|quota|usage`): `Atingi o limite do seu plano por agora. Os painéis continuam funcionando.`
    - for `not logged in` / `login` / `authenticate`: `Preciso que você entre no Claude Code de novo.`
    - for network errors (`ENOTFOUND|ECONNRESET|network|offline`): `Estou sem conexão agora.`
    - otherwise: `Tive um problema e não consegui fazer isso.`
  - `class Brain`:
    - `__init__(cfg, mcp_config: Path, on_api_key_removed: Callable[[], None])`
    - `ask(text: str) -> Iterator[BrainEvent]`. Blocking, one call at a time, guarded by a lock.
    - `new_session() -> None`
    - `needs_new_session(now: datetime) -> bool`. True when idle ≥ `session_idle_hours`.
    - `requests_today: int`
    - `limit_hit: bool`
  - If the `claude` executable is not found, `ask` yields `error` with `Não encontrei o Claude Code instalado.`

### Task 10: App orchestration, hotkey, tray

**Files:**
- Create: `lia/app.py`, `lia/hotkey.py`, `lia/tray.py`
- Test: `tests/test_app_flow.py`

**Interfaces:**
- Consumes: everything above.
- Produces:
  - `class LiaApp(cfg, brain, listener, speaker, window, bridge)` with:
    - `on_hotkey()`
    - `handle_utterance(text: str)`
    - `request_confirmation(card) -> bool` (the bridge's show/hide wiring)
    - `quit()`
  - `main() -> None`

**Flow:**

1. **Hotkey:**
   - Stop the speaker.
   - Show the window.
   - Set state to `listening` and capture an utterance.
   - If a card is pending, route the text to `bridge.voice_answer` first. If it was consumed, stop here.
   - Otherwise, queue the text for the single brain worker thread.
2. **Brain worker** (one thread, FIFO):
   - Set state to `thinking`.
