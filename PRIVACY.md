# Política de Privacidade do Vestion

O Vestion é um assistente de voz pessoal que roda no computador do próprio usuário (Windows). Ele não tem servidor próprio: nenhum dado é enviado ao autor do Vestion.

## Quais dados o Vestion acessa

Com a autorização do usuário pela conta Google, o Vestion acessa:

- **Gmail**: ler, buscar, criar rascunhos e enviar e-mails a pedido do usuário.
- **Google Agenda**: ver, criar, mudar e cancelar compromissos.
- **Google Tasks**: ver, criar, concluir e apagar tarefas (os lembretes do Vestion).

## Como os dados são usados

- Os dados são usados só para atender aos pedidos do próprio usuário e para mostrar o resumo do dia na tela do Vestion.
- O token de acesso fica salvo apenas no computador do usuário, criptografado pelo Windows.
- Para entender os pedidos, o texto do pedido e o conteúdo necessário para respondê-lo são processados pelo Claude (Anthropic), pela conta do próprio usuário.
- Os dados não são vendidos, compartilhados com terceiros para publicidade nem usados para treinar modelos pelo Vestion.

## Uso de dados das APIs do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a [Política de Dados do Usuário dos Serviços de API do Google](https://developers.google.com/terms/api-services-user-data-policy), incluindo os requisitos de Uso Limitado.

## Como remover o acesso

O usuário pode revogar o acesso a qualquer momento em <https://myaccount.google.com/permissions> e apagar a pasta do Vestion do computador.
